# Requisitos Consolidados

## consolidação
| ID | Descrição |
| --- | --- |
| RF001 | O sistema deve exibir a tela de login quando não houver usuário autenticado na sessão. |
| RF002 | O sistema deve permitir que o usuário realize login com e-mail e senha. |
| RF003 | O sistema deve controlar o acesso dos usuários, permitindo ou negando o acesso ao sistema com base nas credenciais cadastradas. |
| RF004 | O sistema deve redirecionar o usuário para a tela principal correspondente ao seu tipo após a autenticação bem-sucedida. |
| RF005 | O sistema deve permitir que o usuário encerre sua sessão (logout). |
| RF006 | O sistema deve permitir que o cliente faça seu próprio cadastro. |
| RF007 | O sistema deve permitir que o administrador edite os dados de um cliente. |
| RF008 | O sistema deve permitir que o administrador exclua um cliente. |
| RF009 | O sistema deve permitir que o administrador cadastre um serviço. |
| RF010 | O sistema deve permitir que o administrador edite os dados de um serviço. |
| RF011 | O sistema deve permitir que o administrador exclua um serviço. |
| RF012 | O sistema deve exibir a lista de serviços cadastrados e permitir a aplicação de filtros. |
| RF013 | O sistema deve permitir que administrador defina o valor de um serviço. |
| RF014 | O sistema deve permitir que o administrador cadastre um profissional. |
| RF015 | O sistema deve permitir que o administrador edite os dados de um profissional. |
| RF016 | O sistema deve permitir que o administrador exclua um profissional. |
| RF017 | O sistema deve exibir uma lista de todos os profissionais cadastrados e deve permitir a aplicação de filtros. |
| RF018 | O sistema deve permitir que o administrador adicione um horário de atendimento do profissional. |
| RF019 | O sistema deve permitir que o administrador remova horários de atendimento. |
| RF020 | O sistema deve permitir que o administrador edite horários de atendimento. |
| RF021 | O sistema deve permitir que o administrador vincule serviços a um profissional. |
| RF022 | O sistema deve permitir ao cliente a seleção da data e hora para criação de um agendamento. |
| RF023 | O sistema deve permitir o cliente a seleção de um serviço para criação de um agendamento. |
| RF024 | O sistema deve permitir o cliente a seleção de um profissional para criação de um agendamento. |
| RF025 | O sistema deve permitir o cliente reagendamento (remarcação) de agendamentos existentes. |
| RF026 | O sistema deve permitir ao administrador a seleção de um cliente para criação de um agendamento. |
| RF027 | O sistema deve permitir ao administrador a seleção da data e hora para criação de um agendamento. |
| RF028 | O sistema deve permitir ao administrador a seleção de um serviço para criação de um agendamento. |
| RF029 | O sistema deve permitir ao administrador a seleção de um profissional para criação de um agendamento. |
| RF030 | O sistema deve permitir ao administrador inserir o valor do desconto serviço do agendamento. |
| RF031 | O sistema deve permitir que administradores e profissionais visualizem a agenda em diferentes modos  e deve permitir a aplicação de filtros. |
| RF032 | O sistema deve permitir que a administrador edite os dados de um agendamento. |
| RF033 | O sistema deve permitir que a administrador exclua um agendamento. |
| RF034 | O sistema deve permitir que profissionais visualizem apenas os agendamentos vinculados a eles. |
| RF035 | O sistema deve exibir apenas os horários disponíveis para a data selecionada no momento da criação de um agendamento. |
| RF036 | O sistema deve validar os campos obrigatórios antes da criação de um agendamento. |
| RNF01 | O sistema deve garantir que apenas usuários autenticados possam realizar operações de leitura e escrita no banco de dados. |
| RNF02 | O sistema deve possuir interface responsiva, adaptando-se a diferentes tamanhos de tela, sendo compatível com dispositivos móveis (celular, tablet) e desktops. |
